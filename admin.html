Admin Account နှင့် Database Rules မသတ်မှတ်ရသေးပါက Cloud Write အလုပ်လုပ်မည်မဟုတ်ပါ။

KAVXY Admin + Index Maintenance Sync

1. Firebase Console > Authentication > Sign-in method: enable Email/Password.
2. Create an admin user under Authentication > Users. Copy its UID.
3. Firebase Console > Project settings > General > Web API Key. Enter it in admin.html Firebase Admin Login.
4. Set Realtime Database rules to allow PUBLIC READ ONLY for the maintenance fields and AUTHENTICATED ADMIN UID WRITE ONLY. Merge these paths with existing rules carefully; do not replace unrelated application rules blindly.

EXAMPLE RULES SNIPPET (merge at root under rules; replace YOUR_ADMIN_UID):
"site_maintenance": { ".read": true, ".write": "auth != null && auth.uid === 'YOUR_ADMIN_UID'" },
"site_maintenance_msg": { ".read": true, ".write": "auth != null && auth.uid === 'YOUR_ADMIN_UID'" },
"maint_est_time": { ".read": true, ".write": "auth != null && auth.uid === 'YOUR_ADMIN_UID'" },
"app_version_config": { ".read": true, ".write": "auth != null && auth.uid === 'YOUR_ADMIN_UID'" },
"site_platform_config": { ".read": true, ".write": "auth != null && auth.uid === 'YOUR_ADMIN_UID'" }

IMPORTANT: If your root .read is false, admin.html's original root fetch may fail. The maintenance controls can still write individual paths with auth, and index.html polls the maintenance field separately. Existing root-based sync may need separately scoped reads or appropriate rules. Do NOT enable global .write:true.

5. Host both updated admin.html and index.html on the same site. Login from Admin panel, toggle Maintenance ON, then open index.html on another device. Turn OFF to restore.
6. Errors now show actual HTTP code / Firebase message in Admin Toast.
7. API key is a public Firebase project identifier, NOT an admin password. Never share your admin password. Password is not stored in localStorage.
8. No Firebase project configuration or security rules have been modified automatically. Live integration needs testing with your real project.
